# Finvilo – landing page

Wspólne cele. Pieniądze pod kontrolą. Landing aplikacji, w której para planuje wspólne cele finansowe, budżet domu i wydatki.

Działa już teraz: kalkulator celu (liczy w przeglądarce, niczego nie wysyła). Ekrany aplikacji są poglądowe, z fikcyjnymi danymi.

Strona statyczna: `index.html`, `styles.css`, `main.js`. Bez frameworka i bez budowania. Powstała w Claude Code ze skillem super-landing-page (AI Product Heroes).
